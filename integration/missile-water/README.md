# Missile 水面豁免回归

运行 `run.bat`；可通过 `MISSILE_WATER_PYTHON` 指定 Python。

测试从当前源码提取水面资格方法、低速/高速高度条件及最终引爆方法，以受控地图和弹体状态执行，覆盖默认关闭、不同水面高度、陆地/岸滩/无效格、沿途跨陆、既有强制引爆和其他轨迹的原路径。它不执行完整飞行循环或实际游戏寻路。

尾段测试直接使用生产 `MissileWaterSurface.h`，覆盖关闭时不追加字节、旧数据默认关闭、启用后回读、部分截断、错误标记/值及多余尾部。类型尾段依赖 `TrajectoryType` 是有边界的 `BulletTypeExt` 最后一个字段；不添加弹体运行时存档字段。完整游戏存读档仍需实测。

只豁免 `LandType::Water` 的高度检查；`SubjectToWater`、碰撞、射程、命中及其他引爆状态保持原判定。岸滩、陆地、无效格继续进行高度检查。没有新增钩子、地址补丁、逐帧全局扫描或单位高度猜测。

产物写入忽略的 `.private`，测试不启动游戏。

stream-test.cpp 另外使用实际 Phobos Stream.cpp 验证尾段读写、旧数据及截断拒绝；只将测试日志输出替换为空函数。

# AI 建筑产线分离回归

本补丁以 `095f42950824d743f1d770021f57e55ca5a6e949` 为基线，完善现有主建筑、防御建筑两条产线，不新增 INI 开关。

## 行为

- 主产线处理非Combat建筑及插件；防御产线处理所有 `BuildCat=Combat` 基地节点，包括挂接插件。插件复用原生宿主适配检查，安装到可用宿主的位置，找不到宿主时不新建付费订单。
- 新任务先经过原版 `AI_Building` 挑选和预处理，再按类别分流。独立产线不再自行扫描整个基地计划；`-1` 防御占位、`-2` 停止、`-3` 围墙以及原版插入电厂的处理保持在原路径。主产线只跳过已接单的那一个防御节点和已放弃的坐标，不会跳过尚未接单的后续防御节点。
- 原版选中的防御节点接单后，下一次规划可以继续选普通建筑，与防御同时施工。防御槽空闲时也要等待原版调度，不会在主产线施工期间自行补取后面的核弹等建筑；防御槽忙或当前节点无法开工时，后续节点继续等待，不能越序挑便宜的节点。
- 防御工厂调用原版 `DemandProduction` 后通过 `Unsuspend(false)` 启动。通过原版 `FindFactory(true, true, true, house)` 找可用建造厂；暂停生产或建造厂不可用时保留进度，建造厂全部消失、玩家接管或所属方战败时取消。
- 完成后在确定性的模拟更新中调用原版放置处理，不向本地输入队列写入 AI 指令。保留原提交的 30 帧重试间隔和八次失败后放弃该坐标的规则。
- 放置返回成功后标记对应节点并清理任务；原版放置中可能删除工厂，通过现有 Detach 注册监听失效，返回后不再解引用旧指针。
- 取消防御生产保留原版退款和对象清理，跳过对主产线生产类型和主产线建造厂的清空。已有其他防御工厂时不覆盖它。
- 保存防御工厂指针、节点位置、重试时间、次数及放弃列表，读档通过现有 Swizzle 恢复指针。需要使用同一版 DLL 新建存档；不兼容旧版存档布局。

## 已核实的原版接口

- `0x42EB50`：主产线节点挑选。共同使用已建检查、全局旗标、Placed、`IsValidBaseNode` 和重新规划的坐标，防御产线不再遗漏后两项语义。
- `0x45038F–0x4503C5`：原版工厂创建后调用 DemandProduction，再调用 Unsuspend。
- `0x4FB0E0`：原版 Place 事件处理函数。使用 YRpp 已有参数契约；其声明丢弃了返回值，本补丁局部适配为 bool。`0x4FB512` 从结果标志返回 AL，`0x4FB5BA` 返回 false，两处均清理 16 字节参数。
- `0x4CA0A1`：复用已有取消生产钩子。自有防御工厂跳至 `0x4CA0E3`，保留此前退款及此后产品释放，跳过原版 `0x4CA0DA` 对主建筑产槽的清空。
- `0x4F7371`：复用现有 House 析构入口，在 ExtMap.Remove 前清理。不能在扩展析构函数中清理：容器可能已先解除所属方的扩展指针，取消生产钩子便无法识别防御产线。整体场景清理由游戏处理原生工厂。

- `0x4FEA3C`（12 字节）新增最终分流入口，覆盖 `mov eax,[esp+10h]; mov ecx,[eax]; mov [ebp+564Ch],ecx`。此处已执行原版节点预处理；`EBP` 是所属方，原始栈 `+0x10` 是已选节点。普通建筑和挂接升级完整重放原指令；防御节点分流后返回 `0x4FEA48`，不向主建筑产槽写入类型。已有两处挑选入口的覆盖宽度不变。

本次修正来自“防御产线开局先造后期核弹”的反馈。旧逻辑按整个计划中的 Combat 类型扫描，绕开了原版发展顺序；`CanBuild` 不能代替 AI 任务调度，也不能把原版的负数占位节点当成可忽略项。共享入口维持原有调用顺序；原版及其他引擎的完整组合仍需游戏实测。

## 自动回归

在具备 Python 3 和 VS C++ x86 工具链的环境中运行：

```powershell
./integration/ai-building-production/run.ps1 -Python python
```

测试提取实际生产控制器、最终分流回调、取消生产分派和六个连续存档字段，只替换原版调用边界。覆盖启动与进度、成功时工厂被删除或保留、失败重试、断电恢复、取消、失效指针、所有权变化、已有其他工厂、升级与分类资格、原版重建坐标及完整存档任务恢复。顺序回归包含全部建筑均可造且买得起时的“电厂→防御占位→科技→核弹”、三类负数占位节点、同类型不同位置的连续任务、防御槽忙以及当前节点资金不足，避免用科技未解锁掩盖越序问题。输出和中间产物保留在已忽略的 `.private/ai-building-production`。

这属于宿主模拟回归，不能替代 Ares/Phobos 联机和原生存读档实测。

## 游戏验收

新开 AI 对局，确认防御顺序先按原版规划展开，不再抢造后面的核弹；防御接单后主建筑仍能并行施工。分别在防御施工、就绪但被挡住两种状态下用本版保存再读取；观察不重新扣费、不换到错误格、不出现重复建筑。再覆盖断电恢复、最后一座建造厂出售或打包、建造厂更换、堵塞八次、建筑摧毁后重建。最后以两台电脑联机验证同步，不能用单机结果代替。

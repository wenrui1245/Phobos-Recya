# 挂载父对象移除回归

运行 run.bat；可设置 ATTACHMENT_TEST_PYTHON 指定 Python。

测试直接从当前 AttachmentClass.cpp 和 Techno Body.cpp 提取失效通知、孤立记录处理、销毁收尾、拥有者列表转移及全局更新入口。地图/单位行为使用受控测试对象，生命周期标识及短期失效引用使用实际 AttachmentRuntime.h。

覆盖移除/非移除通知、父对象先失效且子对象仍存活、停止重生、继承销毁或保留并执行配置任务、重复更新、销毁武器杀死子对象、拥有者重入、当前记录被删除、同地址重建时不误更新新对象。正常存活路径保持原 AI；移除完成前仍由原拥有者负责释放记录。无新钩子、存档字段或全图单位扫描。

稳定更新快照仅遍历既有挂载列表，回调中新建对象留到下一帧，已销毁及同地址替代对象不被旧快照调用。回调期间先移出拥有者列表，避免父对象或相邻挂载的销毁使原遍历失效。

实际舰船沉没、死亡武器、存读档与联机尚需游戏验证；本测试不启动游戏，产物仅写入 .private。

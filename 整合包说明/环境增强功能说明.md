# 环境增强功能说明

本篇说明三个从 **[MO_ExperienceEnhancements](https://github.com/MagicShiba/MO_ExperienceEnhancements)**（心灵终结体验优化拓展，作者 MagicShiba）移植进本平台的独立功能：

| 功能 | 说明 |
| --- | --- |
| **灯光抗锯齿** | 修复光照变化后地形出现的 2:1 明暗阶梯锯齿 |
| **天气系统** | 雨 / 雪 / 火雨 / 云影 / 雾气 / 雷电，含环境音效 |
| **存档截图** | 存档时自动截图，存/读档界面显示预览图 |

三个功能均**只读模拟数据、只写渲染画面与本地文件**，不参与联机模拟，联机开关只影响自己的客户端，**联机安全**。

```{hint}
配置全部写在**游戏目录的用户配置文件**（ra2md.ini，即与 `[Phobos]` 节同一个文件）里，启动时装载一次，**改配置需重进游戏**。
```

---

## 一、灯光抗锯齿

### 原理

每格地形绘制用的调色转换（`CellClass::LightConvert`）是建格子时按当时的全局光照算好的，引擎在光照变化后只重算每格的标量而不重建转换表，于是被光照触发器（如 EVA 调光、地图触发器改光照）影响后，部分格子仍用旧颜色绘制，与已更新的邻居形成 2:1 明暗阶梯。

本功能挂接引擎两处光照重算调用点：光照参数（环境光 + 色调）发生变化时，对全地图逐格重建转换表，使整张地图光照平滑过渡。读档与新开局时也会自动补刷一轮。

### 配置（`[Phobos]` 节）

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `LightConvert.AutoFix` | true | 是否在光照变化后自动重建全格转换表；false = 引擎原版行为 |

### 说明

- 重建有签名去重（光照没变不扫）+ 每秒一次的节流，正常对局无感知开销
- 不提供"染色比例"等 LightingPreset 附属功能（原版菜单功能，未移植）

## 二、天气系统（雨 / 雪 / 火雨 / 云影 / 雾气 / 雷电）

### 使用方法

天气为**纯本地渲染 + 本地音效**，开关默认全关。在 `[Phobos.Weather]` 节里用以下键打开（进游戏即生效）：

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `Rain` | false | 下雨（可与雪同开 = 雨夹雪） |
| `Snow` | false | 下雪 |
| `Fire` | false | 火雨（恒为粒子画法） |
| `Thunder` | false | 雷电（可单独开，不必下雨；闪电 + 打雷） |
| `CloudMode` | 0 | 云层：0 = 关，1 = 云影（云图压暗），2 = 雾气（混向雾色，雾色吃环境光） |

云影 / 雾气与降水**互相独立**：只想要阴天效果，只开 `CloudMode` 即可。

```{note}
雨、雪的开关设计为"本次运行内存态"，本移植版没有 ESC 菜单，故由 ini 给初始值；
若后续需要运行期开关（热键 / 命令），接口 `Weather_SetRain / SetSnow / SetFire / SetThunder` 已预留。
```

### 只给某些地图开天气（地图自带配置）

全局 ini 的开关是**基线**；地图文件本身是 ini 格式，在地图里写一个 `[Phobos.Weather]` 节即可**按同名键覆盖**全局（没写的键继承全局，全局没开的天气在地图里写 `Rain=1` 就能单独打开）：

```ini
; --- 以下内容加进 .map / .yrm 地图文件的文本部分 ---
[Phobos.Weather]
Rain=1
Thunder=1
CloudMode=2
CloudOpacity=90
```

- 开局与读档都会装载地图节；换图后上一张地图的覆盖**不会残留**（每局都重置为全局基线再套地图覆盖）
- 想在"全局开雨"的基线下让某张地图**强制无雨**：地图里写 `Rain=0`
- 地图没有 `[Phobos.Weather]` 节 = 完全继承全局配置
- 全局基线里连 `[Phobos.Weather]` 节都可以不写（全部走默认值），只给需要的地图单独配置

### 画法

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `DrawMode` | image | `image` = 引擎自带的 RAIN/SNOW.SHP 整屏贴图；`particle` = 自绘粒子（雨丝/雪花逐帧推进，更细腻）。火雨恒为粒子 |
| `SpeedScale` | 100 | 所有粒子速度统一倍率（%） |
| `ImageSpeed` | 100 | 图像档播放速度倍率（%） |
| `WeatherLightMix` | 80 | 雨/雪/雾色受环境光照影响的百分比（0 = 纯白原色，100 = 完全跟着光照变暗变色） |

### 云层（云影 / 雾气）

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `CloudOpacity` | 70 | 云层浓度 0~255（压暗/混色共用，0 = 关） |
| `CloudScale` | 400 | 云块尺度（像素，两轴相同） |
| `CloudStyle` | 0 | 风格，写序号或名字都行：0 cumulus 团状积云 / 1 big 大块稀疏 / 2 small 细碎 / 3 sheet 平滑层云 / 4 overcast 阴天 / 5 patchy 疏密不均 / 6 streak 条状云带 / 7 cirrus 卷云 |
| `CloudFogFloor` | 0 | 雾气模式下的最低雾浓度 %（0~100，0 = 最薄处可全透明） |

### 雨

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `RainDensity` | 1500 | 每 1100 平方像素 1 条雨丝（数越小越密） |
| `RainSpeed` | 600,1020 | 下落速度范围（像素/秒，成对参数写 `最小,最大`，只写一个数 = 固定值） |
| `RainAlpha` | 150,220 | 透明度范围 0~255 |
| `RainLen` | 8,20 | 拖尾长度范围（像素） |
| `RainWind` | 25,45 | 风速范围，负 = 向左，单值 = 固定风向 |
| `RainSize` | 1,2 | 雨丝线宽范围 1~4，每颗雨点各抽一个 |
| `RainSplash` | 4,9 | 每个落点溅起几颗水花（0 = 不溅） |
| `RainSplashRate` | 1000 | 每秒落点次数（0 = 按粒子数自动推算） |
| `RippleSize` | 5,9 | 落地水纹最大半径范围（像素，2~12） |
| `RainColor` | 206,227,252 | 雨丝颜色 |

### 雪

## 三、存档截图

### 功能

- **存档时**自动把当前画面截成 16 位 BMP，写到 `<存档目录>\Thumbs\<存档名>.bmp`（旁挂文件，不碰 .SAV 本体）
- **存/读档界面**在面板右侧叠加两个预览框：上框 = 当前画面，下框 = 列表选中存档对应的截图；没有截图的旧存档显示"无截图"占位

### 配置（`[Phobos.SaveShot]` 节）

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `Enable` | true | 总开关；false = 全部回到引擎原版行为 |
| `Width` | 320 | 落盘缩略图宽（像素，高度按视口比例），96~640 |
| `PreviewWidth` | 200 | 对话框里预览框宽（像素，两框上下排），120~420 |

### 说明

- 预览框为**固定叠加**，不改动引擎对话框的列表与按钮布局（MOEx 原版的对话框重做、重命名/删除按钮、输入法输入框均未移植）
- 截图在对话框弹出前一刻抓取，画面里是纯战场（不含菜单）；含天气效果（天气画在战场原图层）
- 存档由 CnCNet 联机生成时同样生效（路径以引擎实际传入为准）

## 四、联机与兼容性说明

- 三个功能都不参与联机模拟，**不会造成不同步**；天气与灯光的开关/参数各客户端可以不同，只影响自己的画面与声音
- 天气、存档截图绘制都发生在"战场原图层"（`DSurface::Composite` 的视口区），因此本平台的无 UI 截图与存档缩略图天然包含天气
- 若同环境其它扩展 DLL（Kaleidoscope 等）占用了相同钩子地址，会有启动冲突提示；出现异常请先关掉对应功能键排查
- 代码来源：MagicShiba/MO_ExperienceEnhancements（GPL 平台内移植引用），移植时有裁剪与 YRpp 化改写，行为与原版可能存在细微差异
